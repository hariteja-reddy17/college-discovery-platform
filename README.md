# College Discovery Platform

A production-oriented frontend MVP for discovering and comparing colleges, built as part of the AI Software Engineer Internship assignment.

## Features

- Searchable college listings
- Filtering and sorting workflows
- Side-by-side college comparison
- Dynamic college detail pages
- Responsive UI design
- Reusable component architecture
- Loading and fallback state handling

## Tech Stack

- Next.js
- React
- TypeScript
- TailwindCSS

## Architecture Highlights

- Reusable UI components
- Centralized compare state management
- Dynamic routing using Next.js App Router
- API-oriented frontend structure
- Scalable folder organization
